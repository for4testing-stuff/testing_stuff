# COMPONENT INVENTORY

- Masthead & Navigation Header: Present across all HTML files (brand logo, date, search input, simulation pause button, primary nav links, dark mode toggle).
- Ticker Bar: Live scrolling market ticker at the top.
- Cards (`.box`): Editorial boxes with stark borders and offset shadows.
- Stock Detail Components: Price charts, key statistics grid, analyst recommendations, historical data tabs.
- Watchlist & Portfolio Table: Holdings table, P&L calculations, advanced analytics metrics (Beta, VaR 95%, Sharpe Ratio, Dividend Yield).
- Side-by-Side Comparison Engine (`compare.html`): 3-company dropdown selectors, multi-metric comparison table, normalized 30-day performance chart.
- Learning & QA Dashboards (`learn.html`, `qa.html`).
