# FEATURE INVENTORY

1. **Real-time Price Simulation Engine**: Periodic updates to stock prices, indices, and portfolio values.
2. **Watchlist & Portfolio Management**: Add/remove stocks, track quantity, invested vs current value, P&L.
3. **Advanced Portfolio Risk Analytics**: Beta, VaR 95%, Sharpe Ratio, and Dividend Yield calculations.
4. **Side-by-Side Multi-Company Comparison**: Compare up to 3 stocks across 11 fundamental/technical metrics + normalized 30-day price chart.
5. **AI Insights & LLM Bridge**: Optional OpenAI/Anthropic integration or simulated AI summaries.
6. **Dark Mode Toggle**: Persistent light/dark mode switch.
7. **Interactive Charts**: Chart.js graphs for stocks and portfolio.
8. **Learning Center & FAQ**: Financial education modules.
9. **QA Testing Dashboard**: Automated test results and QA report view.
