# REPO MAP

- Root Files:
  - `index.html`: Home / Markets overview page.
  - `watchlist.html`: Watchlist and Portfolio holdings page.
  - `stock.html`: Individual stock detail page.
  - `compare.html`: Multi-company side-by-side comparison page.
  - `learn.html`: Financial learning hub and FAQ.
  - `qa.html`: QA Report dashboard.
  - `presentation.html`: Project presentation / demo view.
  - `README.md`: Project documentation.
- Folders:
  - `css/`: Stylesheets (`styles.css`).
  - `js/`: Application logic (`app.js`, `charts.js`, `data.js`, `dividend.js`, `head-template.html`, `insights.js`, `ai-bridge.js`).
  - `code/`: Additional lab components and CSS animations (`animation-lab.html`, `animations.css`, `animations.js`, `charts.js`).
  - `docs/`, `reference/`, `upgrade/`, `new prompt/`: Planning and reference assets.
