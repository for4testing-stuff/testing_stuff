# STYLING ARCHITECTURE

- Master Stylesheet: `css/styles.css`
- Design System Tokens: CSS Custom Properties in `:root` (`--paper`, `--ink`, `--orange`, `--surface`, `--line-color`, `--gain`, `--loss`, `--mute`, `--shadow`, fonts).
- Dark Mode Overrides: `body.dark-mode` overrides variables and box/table background colors.
- Typography: Serif display (`Playfair Display`, `Lora`), Sans-serif (`Inter`), Monospace (`IBM Plex Mono` with tabular numbers).
- Animation Styles: `code/animations.css` and keyframes defined in master CSS.
