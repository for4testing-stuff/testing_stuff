# DESIGN SYSTEM

## Visual Direction
- **Product Personality**: Authoritative, Modern, Editorial, Precise.
- **Justification**: Bourse·Daily is a professional financial terminal that blends traditional financial newspaper editorial layout with high-speed modern digital market intelligence and real-time simulations.
- **Light/Dark Approach**: Supports both pristine Orange & White editorial theme (default) and a robust Dark Mode theme (`body.dark-mode`), fully toggleable with persistent user preference storage.
- **Color Palette**:
  - Paper: `#ffffff` (Light) / `#121212` (Dark)
  - Ink: `#0f172a` (Light) / `#f8fafc` (Dark)
  - Orange Accent: `#f97316` (Primary) / `#ea580c` (Dark)
  - Surface: `#fff7ed` (Light) / `#1e1b18` (Dark)
  - Gain: `#16a34a`
  - Loss: `#dc2626`
- **Typography**: Display serif (`Playfair Display`, `Lora`), Sans-serif (`Inter`), Monospace (`IBM Plex Mono` with tabular numerics).
- **Motion Rule**: Buttery-smooth slide and fade entrances (`cubic-bezier(0.16, 1, 0.3, 1)`) with reduced motion accessibility compliance.
