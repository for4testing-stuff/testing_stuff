Text and string animation

#16 · strings
16Masked line reveal

Each line sits in an overflow-hidden mask and slides up from 105%, 110ms apart. Lines are passed as an array so wrapping never changes.

S1Character stagger
Banks lead the rally

Each character rises 0.5em and fades in, 28ms apart. aria-label keeps the full sentence for screen readers.

S2Scramble to symbol
MRDN

Letters lock left to right out of random glyphs. Used when a stock page loads and when the live ticker swaps a symbol.

S3Typewriter + caret

35 to 65ms per character, random jitter so it feels typed. The caret blinks with steps(1), a hard blink like a terminal.

4Number count-up (Indian format)
₹0
▲ 0.00% today

900ms, ease-out cubic, requestAnimationFrame. Lakh grouping (4,82,300) is done by toLocaleString('en-IN'), tabular digits stop the width jittering.

Buttons, stars and inputs

#10 · #11
10Hard-shadow press

Hover lifts 1px (shadow grows). Press moves 3px,3px and the shadow shrinks to zero, so the button sits flat on the paper like a stamp.

10Add to Watchlist, then Added

The star spins 144° while scaling to 1.35 and back. The label swaps to "Added" and an SVG tick draws itself (stroke-dashoffset). No emoji.

11Star toggle + row collapse

Pop on toggle. Un-starring a row fades it left, then collapses its height so the rows below slide up, then the count updates: 3 in list.

I1Input underline + search dropdown

    A 3px yellow underline draws from the left on focus. Suggestions drop in 25ms apart, each 4px up to rest.
